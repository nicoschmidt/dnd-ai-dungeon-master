# Provenance: built-in adventure content

Everything below this directory is either SRD material or original work
written for this project. None of it comes from a published adventure. Every
file added here gets a row below.

| File | Source |
| --- | --- |
| `iteration-001/monsters/ogre.json` | The Ogre stat block from the System Reference Document 5.2.1, page 312, transcribed into this project's monster model. Only the values `docs/domain/combat.md` uses are kept; the Ogre's gear (three javelins), speed, senses and languages are left out. |
| `iteration-001/encounters/iteration-001.json` | Original work for this project: the premise of the fight, written for iteration 001. |
